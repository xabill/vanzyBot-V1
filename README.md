# 🌌 INTRODUCTION

**vanzyBot-V1** adalah WhatsApp automation bot berbasis Node.js menggunakan library Baileys.

Bot ini dibuat untuk kebutuhan:
- automation chat WhatsApp
- management group
- downloader media
- tools entertainment
- sistem modular command

Bot ini dirancang ringan, stabil, dan mudah dikembangkan oleh developer pemula maupun advanced.

# 🛠 INSTALLATION GUIDE

## 1. Clone Repository
```bash
git clone https://github.com/xabill/vanzyBot-V1
cd vanzyBot-V1
```

## 2. Install Dependencies
```bash
npm install
```

## 3. Run Bot
```bash
node index.js
```

# ❓ FAQ

## Q: Bot tidak jalan?
A: Cek Node.js version dan install dependencies ulang.

## Q: QR tidak muncul?
A: Hapus folder session lalu run ulang.

## Q: Error module?
A: Jalankan `npm install` lagi.

---

# 🧠 TROUBLESHOOTING

✔ Delete node_modules lalu install ulang  
✔ Pastikan ffmpeg sudah terinstall  
✔ Gunakan Node LTS  
✔ Jangan edit system core tanpa paham
