## 📌 Introduction

**VanzyBot-V1** adalah WhatsApp bot berbasis Node.js dan Baileys Multi-Device yang dirancang untuk automasi grup, AI chat, media downloader, serta berbagai fitur hiburan.

Bot ini dibuat dengan sistem modular, sehingga setiap fitur dapat dikembangkan tanpa mengganggu sistem utama.

---

## ✨ Main Features

### 🤖 AI System
- OpenAI GPT integration
- Google Gemini support
- Anthropic Claude support
- Multi-key rotation system

### 💬 Chat System
- Auto reply group chat
- Private chat assistant
- Mention-based response
- Smart conversation memory

### 📥 Downloader System
- YouTube video/audio
- TikTok downloader
- Instagram reels/posts
- Facebook video
- Twitter/X media
- Pinterest images

### 🎭 Entertainment
- Anime reaction GIFs
- Emoji mix generator
- Random meme generator
- Fun command system

### 🛡️ Group Management
- Anti-link protection
- Auto welcome & goodbye
- Kick, ban, promote, demote
- Tag all members
- Admin control system

### 🔖 Sticker System
- Image to sticker
- Video to sticker
- Text to sticker
- Animated sticker support

### 🧩 Plugin System
- Dynamic plugin loader
- Install via URL
- No restart required
- Easy customization

### ☁️ Database
- MongoDB integration
- Persistent settings
- User tracking system
- Group configuration save
