# ⚙️ INSTALLATION SYSTEM

## 📦 STEP 1 — CLONE PROJECT
```bash
git clone https://github.com/xabill/vanzyBot-V1
cd vanzyBot-V1
```

## 📥 STEP 2 — INSTALL DEPENDENCIES
```bash
npm install
```

## ▶ STEP 3 — RUN SYSTEM
```bash
node index.js
```
